# TaskFlow

A responsive and lightweight landing page for a SaaS project management application.

## Tech Stack

- **HTML5**: Semantic layout elements.
- **CSS3**: Variables, Flexbox, Grid, and Media Queries.
- **JavaScript**: Theme toggle, validations, and API integration.

## Key Features

- **Dark Mode**: Persisted dark/light theme switch using local storage.
- **Form Validation**: Blur-based client-side check on the contact fields.
- **API Feed**: Renders 6 blog posts from JSONPlaceholder, including loading skeleton panels.
- **Responsiveness**: Smooth transitions from widescreen desktop columns down to single-column mobile views.
